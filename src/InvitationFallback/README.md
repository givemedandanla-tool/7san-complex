# 七聖角色邀約：四牌手換策略試跑版 0.1.0

這是一個可放入 BetterGI 的 JS 套件。為同一位邀約角色依序使用已建立的牌組；確認敗北後，退出該局、回到同一對手的準備頁、換另一套牌組及牌手再打。任一策略獲勝便停止並保留結算頁。

**狀態：已做離線流程、實際牌手載入與素材完整性測試；尚未在原神／BetterGI 遊戲會話實測。** 邀約前後的介面流程可能因遊戲版本而需要調整；辨識不明時會停下並留下現場，不會繼續亂點。

## 安裝

1. 解壓 `InvitationFallback-0.1.0.zip`。
2. 將整個 `InvitationFallback` 資料夾放到 BetterGI 的 `User/JsScript/`。
3. 確認路徑是 `User/JsScript/InvitationFallback/manifest.json`，避免多套一層同名目錄。
4. 在 BetterGI 調度器新增此 JS，開啟「修改 JS 腳本自訂配置」。此版本不需要另外訂閱四套牌手，也不需要開啟 HTTP 或通知權限。

## 環境

- BetterGI 0.66.0 或以上。
- **遊戲語言為簡體中文，實際遊戲客戶區為 1920×1080**。調整後重新啟動 BetterGI 捕獲器。
- 渲染精度建議 1.0，至少符合原牌手已知要求 0.8；保持整局解析度不變。
- 先設定好 BetterGI 的停止按鍵。牌局期間讓腳本獨占鍵鼠操作。
- 套件不會自動組牌或購買卡牌。牌組角色順序與所需行動牌請參考 `engines/<牌手>/README.md`，各文件附原牌表與分享碼。

## 第一次測試：換牌組與敗北重打

假設你準備測試「雷柯刻 → 伊嘉早」：

1. 在遊戲中先建好兩套牌組，名稱分別設成 `雷柯刻`、`伊嘉早`，建議放在牌組清單第一頁。
2. 雷柯刻角色從左到右為**雷電將軍／柯萊／刻晴**；伊嘉早為**伊安珊／嘉明／早柚**。依各自 README 準備行動牌。程式按牌組名稱選擇，不會完整盤點你配了哪些牌。
3. 先手動邀請要測試的角色。進入顯示該角色名稱的邀約詳情頁；也可停在有「我方出战牌组」的對局準備頁，但該頁仍須能辨識對手姓名。**先不要按開始，也不要停在敗北結算頁。**
4. 設定：

| 欄位 | 範例 |
|---|---|
| 執行入口 | `已选对手（换牌组重打）` |
| 對手全名 | `迪卢克`（遊戲簡體中文） |
| 難度 | `友好对局`，與你遊戲中選擇一致 |
| 嘗試順序 | `雷柯刻,伊嘉早` |
| 雷柯刻牌組名 | `雷柯刻` |
| 伊嘉早牌組名 | `伊嘉早` |
| 最多對局 | `2` |

5. 執行腳本。會先確認對手、選第一套牌組並開局；若輸，退出後重開同一位，換第二套。若第一套已贏，就正常結束，不會故意再輸一次。

若準備頁省略對手姓名，請退回能看到姓名的邀約詳情頁再啟動。這是防止誤挑另一人的必要確認，不會默默忽略。

**這次只處理一位對手、一種難度。** 不會自動遍歷下一位、連跑雙難度或每週來客。所有策略用盡則視為未完成並停止。

## 單獨確認牌手能運作

如果想先排除對局前後 UI 的影響：手動選正確牌組、進入初始手牌／首次選人／首次重投頁，選 `初始手牌（只测一局）`。只執行嘗試順序中的第一套，不會切換牌組，也不會在敗北後重開。

這個模式只驗證單局牌手，不等同換牌組重試流程已成功。

各名稱用逗號分隔，每種策略只嘗試一次；可只填自己擁有的牌組。找不到名稱的牌組會在開局前跳過。辨識／操作異常會停止，不會當成正常敗北去換策略。

## 原邀約導航（實驗入口）

`原邀约导航（实验）` 保留原作者前往貓尾、走到邀請板、找小王子買函的操作路線，改為選取你填寫的那位角色及指定難度，接到同一套重試流程。一次仍只有一位。

- 先準備至少一張邀請函；若目標已邀請，現有邀請函數量填 `1` 即可。
- 自動購函預設關閉；只有在你勾選並把數量填 `0` 時，才會依原路線嘗試購買 **1 張**。
- 購買前須確認數量為 1，購買只提交一次，必須看到獲得邀請函的結果；不明時會寫下待確認狀態並停止。重跑前請檢查遊戲庫存、填入實際數量，避免重複購買。
- 沒找到所填角色或難度就停止，不沿用原程式「直接點第一格」的假設。
- 此路線比已選對手入口多了走位、對話與商店位置等變數，建議核心重試流程驗證後再測。

## 停止、結果與回報

- 使用 BetterGI 原有停止按鈕／熱鍵；停止或技術錯誤不會自動跳到下一套牌手。
- 獲勝以「对局胜利」為準，**不代表友好對局額外目標全數完成**。
- 最後結果與嘗試紀錄：`data/last-run.json`。
- 失敗時的 OCR 文字與座標：`data/last-error.json`。
- 可選的現場截圖：`data/last-error.png`。只保存在本機，可能包含 UID；回報前請自行遮蔽個人資訊。
- 四套牌手原有詳細日誌：`engines/<牌手>/logs/`。

首次測試若卡住，提供停止訊息、last-error.json 與已遮蔽資訊的 last-error.png，便能針對實際介面調整 `ui-profile.json`。不需要提供帳號、密碼或任何權杖。
